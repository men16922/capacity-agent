# 불일치와 미확인 사항

2026-09-27 원문 조사 결과다. 아래 항목을 임의로 고친 뒤 원문과 일치한다고 표현하지 않는다. 페이지는 PDF 물리 페이지다.

| ID | 확인한 근거 | 판단과 다음 처리 |

| Q01 | 강의 03 p.9의 내장디스크 식은 영역 합계에 SWAP을 곱한다. TTA R3 p.36은 SWAP을 용량으로 더한다. | 차원이 맞는 R3 본문을 첫 계산 모델로 사용. 슬라이드는 원문 그대로 보존 |
| Q02 | 두 XLS의 `WEB_WAS산정!F16`은 `F6*F8*F10*F12*F14`, 출력 표기는 OPS. R3 p.20에는 업무용도·기본 OPS·연계·클러스터·목표 활용률·단위 보정이 있다. | XLS와 R3를 별도 규칙으로 관리. 결과 동등성을 요구하지 않음 |
| Q03 | XLS `메모리용량산정!F20`은 관리자 영역과 클러스터 계수를 포함. R3 p.33 식은 시스템·사용자·애플리케이션 메모리를 사용 | 같은 이름의 계산기라도 입력 계약부터 구분 |
| Q04 | XLS `디스크용량산정!F20`에는 파일시스템·RAID 계수가 없고 F22에는 파일시스템 계수가 없다. | 레거시 호환 요구 시 원식 재현과 개선식을 분리 |
| Q05 | R3 p.44는 약 5,585MB 필요량 뒤 “실제로 1,024MB로 선정”이라고 기재 | 화면 렌더링으로 원문 확인. 산정량 미만의 선정값을 채택하지 않음. 공식 정오표 확인 필요 |
| Q06 | R3 p.47의 DB 시스템 디스크 설명은 약 12,167MB, 같은 페이지 표는 64,723MB | 입력 `(10240+8192+16384)*1.1*1.3*1.3`의 독립 산술 결과는 64,722.944. 표의 반올림 값과 일치. 설명 문구는 정답에서 제외 |
| Q07 | R3 부록 p.40의 사용량 조사값과 p.41~43에서 선정하는 동시 사용자·업무 빈도의 일부 값이 다름 | 예시의 관측값·선정값을 자동 혼합하지 않음. fixture에 실제 사용한 값을 명시 |
| Q08 | R3 p.35의 포맷 공간 추가 고려와 표 7-14의 파일시스템 1.1이 함께 제시됨 | 자동 추가 보정으로 중복 계산하지 않음. 기본 식 외 추가 보정은 별도 정책과 이유 필요 |
| Q09 | RAID5 1.3·RAID6 1.4는 원문의 계수 | 모든 실제 디스크 구성에 정확한 효율로 적용하지 않음. 토폴로지별 계산은 후속 모델 |
| Q10 | 추가 네트워크 가이드 p.3에서 TTAK.KO-01.0103/R1(2017-06-28) 확인. p.8~9에 패킷 상수 1,488,095 제시 | 가이드 프로파일에 이론적 PPS 구현. 표준 원문·현행성·실제 프레임 조건의 검증은 별도 |
| Q11 | XLS 03·05는 서로 다른 SHA-256. 이번에 추출한 시트·셀 값·수식은 같음 | 둘 다 보존. 두 파일 각각 OLTP F14/F18/F22/F34의 BIFF 수식 추출 미해결. Excel 재계산·컨트롤 검증 필요 |
| Q12 | XLS WEB/WAS F6=549는 저장값, H6=1000과 자동 수식 연결을 확인하지 못함 | 원본을 완전한 실시간 계산기로 가정하지 않음. 값의 생성 경로 검토 필요 |
| Q13 | ISMS/ISMS-P 파일의 현행 버전·적용 범위 미확인 | 인증 판정용으로 활성화하지 않음. 향후 공식 기준과 항목별 대조 |
| Q14 | HWP 6개는 문단 추출만 수행. XLSX의 내장 이미지·표 배치 미검증 | 텍스트 검색용 사용. 완전한 문서 변환 또는 이미지 검수 완료로 표시하지 않음 |
| Q15 | TTA 공식 검색 목록에서 R3 확인, 상세 페이지 열기 실패 | 최신 유효본·정오표의 완전 확인은 미완료. 현재는 첨부 R3 버전에 고정 |

| Q16 | 추가 AWS 워크북은 TTA 원문의 MB를 MiB로 재현하고 GiB로 환산 | 워크북 고유 해석으로 표시. 엔진 단위 계약에서 자동 등치하지 않음 |
| Q17 | 추가 워크북 `검증!A29`의 TTA 13개·AWS 19개 PASS 문구, EC2 사양 36행 | 원본 주장과 이번 검증을 분리. 네이티브 재계산·시나리오 재실행·사양 전수 대조는 미수행 |

| Q18 | 추가 사용 가이드 p.16의 엑셀 식별 해시 `921f6e1bfb9d63c2`와 현재 엑셀 `d6bfd84a3ce8ede1` 불일치. 가이드 p.15의 `검증!A34` 문구는 현재 엑셀 `A29`에 위치 | 다른 버전으로 취급. 셀 주소·기본값은 현재 엑셀 대조. 원본 변경 없이 두 자료를 모두 보존 |

| Q19 | 네트워크 가이드 p.8~9 안정성 계수 100~150%, p.14 UI 설명 100~200% | 본문 표 1~1.5를 엔진 계약에 채택하고 차이를 명시 |
| Q20 | 네트워크 가이드의 업링크 F(x)는 후보집합 미명세, L4/L7 입력 표는 평균 유지시간 누락, 최초 증가율100 표기 모호 | 선택 링크 속도·평균 세션시간·증가분을 명시적으로 입력. 제품 정책과 원문식을 구분 |

| Q21 | 2024.06 클라우드 취약점 가이드 p.8은 제품 기능·버전·운영상황별 판단 차이를 명시. 766페이지의 전체 명령·현행성은 미검증 | 자산·제품 버전과 적용 여부를 먼저 확인. 출처 기반 점검표와 실제 증적을 분리하고 자동 조치·일괄 양호 판정에 사용하지 않음 |
