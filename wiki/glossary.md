# 용어와 단위

| 용어 | 이 프로젝트에서 구분할 의미 |
| --- | --- |
| 전체 사용자 | 등록 또는 대상 인구. 동시 사용자와 구분 |
| 동시 사용자 | 정해진 관측 구간에 동시에 서비스를 이용하는 사용자 |
| TPS | 업무 트랜잭션/초. 업무 정의와 측정 조건 필요 |
| tpmC | TPC-C 성능 지표. 일반 업무의 분당 트랜잭션과 직접 동일시하지 않음 |
| max-jOPS | SPECjbb2015 처리량 지표. 실행 범주와 구성 조건 필요 |
| critical-jOPS | 응답시간 제약을 고려한 SPECjbb2015 지표 |
| IOPS | 초당 입출력 동작 수. 작업 크기·읽기/쓰기·지연 조건 별도 |
| bps | bit/초. Byte 기반 전송량과 구분 |
| 논리 용량 / 물리 용량 | 사용자가 쓸 데이터 공간 / 보호·관리 영역을 포함한 장치 공간 |
| 여유 계수 | 예: 추가 30%를 `1.3`으로 표시. 목표 활용률 `0.7`과 다른 값 |
| 규칙 버전 | 계산식·계수·단위·반올림 정책을 묶은 재현 가능한 식별자 |
