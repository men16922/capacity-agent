## 우선 읽은 항목과 제품 연결

- Docker 체크리스트 p.511: 5영역·32항목. PIDs 제한 p.543은 프로세스 수에 대한 제한이며 CPU·메모리 용량 공식이 아니다.
- Kubernetes 관리 영역 p.549: 6영역·17항목. 워커 p.571: 3영역·7항목. 역할별 적용 범위를 구분한다.
- Ceph p.677: 3영역·7항목. 네트워크 장비 p.699: 4영역·12항목. 스토리지 p.743: 계정 관리 5항목.
- KVM 로그·백업 p.18, API Server 로그 p.557은 수집량·보관·백업 가정을 확인하는 질문과 연결한다.
- etcd 암호화·TLS p.560~561은 기능을 적용한 구성의 성능 검토와 연결한다. 임의 보정계수를 추가하지 않는다.

구체적인 연결 방법은 [클라우드 보안과 산정](../concepts/cloud-security.md)에 정리했다. On-Prem/AWS 마이그레이션에서는 실제 선택한 제품·운영 주체에 맞는 항목만 연결한다.

## 확인 수준

766페이지의 텍스트를 추출하고 목차·개요·주요 체크리스트와 관련 항목을 읽었다. PDF p.7과 p.549는 렌더 이미지로도 표·본문을 확인했다. 전체 명령·그림·화면의 전수 검증은 미수행이며 p.1 등 일부 글자 추출은 불완전하다. 문서의 설정 예제를 실행하거나 시스템을 점검·변경하지 않았다. 각 명령의 대상 버전·철자·지원 여부는 실제 적용 전에 공식 문서와 대조해야 한다.
