## 엔진 적용

[network-guide-2021 프로파일](../../docs/NETWORK_ENGINE.md)에 가이드 기반 식 10개를 구현했다. 강의 07의 `lecture-network`와 구분하며 출처를 이 가이드의 물리 페이지에 연결한다. 전체 표준의 모든 조건을 이행하거나 현재 법적 의무에 부합한다고 주장하지 않는다.

- 접속 포트 수는 확장·안정성 계수를 곱한 뒤 실제 포트 요구량을 올림한다.
- 스위칭은 실제 선택한 포트 용량 합에 양방향 계수 2를 적용한다. PPS에는 이 계수를 다시 적용하지 않는다.
- 1,488,095는 가이드가 제시하는 1GE 이론적 패킷 상수다. 실제 패킷 크기·기능 활성화·장비 성능을 측정한 값이 아니다.
- L4/L7은 세션당 데이터량과 평균 유지시간이 함께 있어야 bps를 계산할 수 있다. 엔진에서는 데이터량을 명시적 bytes/session으로 받아 8을 곱한다.
- WDM은 사용자가 선택한 Line 인터페이스 용량과 포트를 기반으로 전송 요구량만 계산한다. Client→Line 매핑이나 파장·장비 선택을 자동 결정하지 않는다.

## 확인이 필요한 차이

1. p.8~9 본문 표의 안정성 계수는 100~150%, p.14 시스템 입력 설명은 100~200%다. 현재 엔진은 본문 표 1.0~1.5를 적용한다. 범위 변경에는 별도 규칙 버전과 근거가 필요하다.
2. p.8의 `F(업링크 용량)`은 후보 인터페이스 집합·최대 포트 수·정렬 우선순위를 명세하지 않는다. 엔진은 선택한 링크 속도를 입력받고, 경로당 필요 포트를 올림한 뒤 1 또는 2개의 전체 용량 경로를 반영하는 제품 정책을 명시한다. 실제 장비 추천이나 장애 전환 보장은 아니다.
3. p.9의 L4/L7 입력 표에는 평균 유지시간이 없지만 식과 p.14에는 있다. 엔진에서는 필수값이다.
4. p.14의 최초 도입 시 증가율 `100` 표기는 성장률과 성장배수 해석이 모호하다. 엔진 `growth_rate`는 증가분이다. 20% 성장=0.2, 성장 없음=0이며 `(1+growth_rate)`를 한 번 적용한다. 3개년 평균이라는 설명을 3년 복리 지수로 바꾸지 않는다.
5. MSPP·캐리어이더넷은 p.6에 입력/결과 목록만 있으며 본문에 재현 가능한 상세 식이 없다. p.11에는 전송 장비를 당시 시스템에서 추후 제공할 예정이라고 적혀 있다. 명시된 WDM 식과 기타 미명세 장비를 구분한다.

원본 텍스트와 표를 읽었다. 사이트의 현재 운영 상태, 법령·표준의 현행성, 화면 속 시험 장비의 실제 판매·성능은 검증하지 않았다. 계정 생성·메일 발송·외부 장비 조회도 실행하지 않았다.
