# Lessons

- 2026-09-27: macOS 한글 파일명은 NFD일 수 있다. 이름을 검색할 때 NFC로 비교하되 원본 경로를 변경하지 않고 실제 경로를 manifest와 링크에 보존한다.
- 2026-09-27: AWS 가격 CSV의 Windows 항목은 OS 문자열만으로 필터하지 않는다. Shared·NA·Used·OnDemand와 RunInstances:0002를 함께 확인한다.
- 2026-09-27: gp3 처리량 단가의 GiBps-mo는 MiB/s 입력과 1024배 차이다. 실제 단가 단위와 독립 계산 fixture를 함께 검증한다.
- 2026-09-27: 인쇄 CSS가 AppLayout을 숨기면 탐색이 접힐 수 있다. 인쇄 본문은 별도 루트에 두고 화면 복귀 후 탐색 버튼까지 검증한다.
- 2026-09-28: 연속 비동기 산정 결과의 동기 상태 갱신은 Cloudscape 표에서 React185를 일으킬 수 있었다. 네트워크 예외와 화면 갱신을 분리하고 startTransition으로 처리한 뒤 48개 부분 실패·200개 전체 처리 각6회로 재확인했다.
- 2026-09-28: 접근성 색상 대비는 알림의 진입 애니메이션 중 오탐할 수 있다. 고정 sleep 대신 실제 animation.finished 이후 검사하고 안정 상태의 위반을 판정한다.
- 2026-09-28: 카탈로그의64.00과 입력64처럼 같은 사양은 문자열이 아니라 정확한 숫자로 비교한다. 프로젝트 동시 편집은 IndexedDB 트랜잭션의 revision 검사로 보호하고, 새 화면 테스트는 실제 경로/제목 전환을 기다린다.
