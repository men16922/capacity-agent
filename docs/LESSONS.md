# Lessons

- 2026-09-27: macOS 한글 파일명은 NFD일 수 있다. 이름을 검색할 때 NFC로 비교하되 원본 경로를 변경하지 않고 실제 경로를 manifest와 링크에 보존한다.
- 2026-09-27: AWS 가격 CSV의 Windows 항목은 OS 문자열만으로 필터하지 않는다. Shared·NA·Used·OnDemand와 RunInstances:0002를 함께 확인한다.
- 2026-09-27: gp3 처리량 단가의 GiBps-mo는 MiB/s 입력과 1024배 차이다. 실제 단가 단위와 독립 계산 fixture를 함께 검증한다.
- 2026-09-27: 인쇄 CSS가 AppLayout을 숨기면 탐색이 접힐 수 있다. 인쇄 본문은 별도 루트에 두고 화면 복귀 후 탐색 버튼까지 검증한다.
