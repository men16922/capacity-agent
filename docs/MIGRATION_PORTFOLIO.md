# 다수 자산 AWS 이전 설계

2026-09-28 · 사용자가 요청한 수십 개 On-Prem 자산 동시 검토를 위한 P2.1 설계.

## 화면과 흐름

On-Prem CSV 등록 → AWS 이전 설계 목록 → 선택 자산 공통 조건 적용·일괄 산정 → 개별 상세 → 검토한 이전안 저장·산정서.

- 목록은 최대 200개 서버를 다룬다. 이름/ID 검색, 역할·산정 상태 필터, 정렬, 페이지 이동, 전체 검색 결과 선택을 제공한다. WEB/WAS·DB·BATCH는 자산 역할이며 3개 시스템으로 합치지 않는다.
- 각 행은 원본 CPU/메모리, 요구량, 선택 EC2, gp3, 월 비용, 상태를 연결한다. 이름을 누르면 별도 상세 화면으로 이동한다. 상세 주소를 새로고침해도 해당 자산을 표시한다. 상세에서 복귀하거나 뒤로 가면 세션 내 목록 탐색 상태를 유지한다. 페이지 전체 새로고침 시 목록 필터·선택은 초기화한다.
- 상세는 요약, 원본 사양, 이전 조건, EC2 후보, 계산 근거 탭으로 나눈다. 기존 단계별 편집기는 상세에서 연다. 개별 후보 변경 및 검토 후 저장을 지원한다.

## 계산과 저장

- 모든 자산은 기존 결정론적 `/api/migrate`로 독립 계산한다. 최대 4개 동시 요청, 자산별 성공·입력 오류·후보 없음·통신 실패를 보존한다. 한 건의 오류가 나머지를 중단하지 않는다.
- 중지는 완료 건을 유지하고 진행 요청을 취소한다. 화면을 나가거나 다른 프로젝트로 이동하면 미완료 응답을 폐기한다.
- 공통 조건은 선택한 자산의 성장률·연수·CPU/메모리 목표 사용률·월 사용시간에만 적용한다. OS·ARM 호환성·상대성능 근거·HA 검증은 개별 검토한다. 빈 값은 해당 자산의 값을 유지한다.
- 계산 초안은 자산 ID당 1개다. 원본 스냅샷·조건·선택 후보·요구량·근거를 보관하고 후보 전체는 상세에서 다시 조회한다. 중복 카탈로그 저장을 줄여 수십 개 자산의 브라우저 저장을 지원한다.
- 원본·조건·카탈로그 버전이 바뀌면 재산정 필요로 표시한다. 미산정·실패·후보 없음·오래된 결과를 월 비용 합계에서 제외하고 포함 건수를 표시한다. 합계는 EC2+EBS 부분 비용이며 전체 이전 비용이 아니다.
- 자동 선택된 후보는 검토 전 초안이다. 저장된 이전안은 별도 불변 스냅샷으로 유지하며 현재 자산과 달라도 변경하지 않는다. 자산 통합·DB 재구성·RDS 변환·의존성/Wave 자동 설계는 범위 밖이다.
- schemaVersion 1의 기존 프로젝트와 호환되는 선택 필드 `migrationDrafts`를 추가한다. JSON 가져오기는 초안 입력을 현재 엔진으로 재계산하고 외부 결과 금액을 신뢰하지 않는다.

## 검증 기준

48개 합성 자산의 일괄 처리, 부분 실패 분리, 검색·페이지·선택 범위, 개별 상세와 조건 변경, 오래된 결과 합계 제외, 취소·늦은 응답, 저장/재로딩 및 JSON 재계산을 실제 브라우저에서 검증한다. 기존 golden 값과 단건 시나리오 복제·산정서·접근성 검증도 유지한다.

## 구현 구성

- `web/src/Portfolio.tsx`: 자산 목록, 4개 요청 동시 실행, 선택 범위/필터/공통 조건/CSV.
- `web/src/MigrationDetail.tsx`: 별도 자산 상세, 전체 후보 재조회, 후보 변경·검토 저장.
- `web/src/migrationState.ts`: 정규화 입력 비교, 상태 판정, 압축 결과와 초안 교체.
- `web/src/App.tsx`: 프로젝트 범위의 해시 탐색. `projectStore.ts`: IndexedDB 저장과 가져오기 재계산. 이전안 한도 200개.
- `web/src/references.ts`, `ui.tsx`: 공식 출처와 표시 단위, 범용 견적 필드.

조건 변경은 초안을 즉시 저장하며 화면 상단에서 이를 안내한다. 편집기의 `상세로 돌아가기`는 화면을 나가는 동작이며 이미 변경한 초안을 되돌리지 않는다. 저장 이전안을 복제한 편집기는 별도 초안을 자동 저장하지 않으므로 `취소`를 사용한다. 과거 검토 완료 이전안은 영향받지 않는다. 전체 후보 재조회에 실패하면 기존 요약은 남지만 신규 검토 저장은 차단하고 재시도를 안내한다.

견적 데이터 사전과 지원/미지원 구분은 [ESTIMATION_INPUTS](ESTIMATION_INPUTS.md)를 따른다. 원본·식 ID·해시와 JSON 계산 단위는 유지하고 사람이 읽는 출처/단위 표기만 정리한다.

## 선택 이전안 일괄 저장

목록의 선택 건을 검토 창에서 확인한 후 한 번에 저장한다. 최신 입력·후보가 있고 동일 입력/선택 후보의 저장안이 없으며 총200개 한도 안에 있어야 한다. 하나라도 조건을 충족하지 않으면 전체 저장을 차단한다. 저장은 한 프로젝트 상태 변경과 IndexedDB 트랜잭션으로 처리한다. 성공 시 각 자산이 별도 이전안 행이 된다. [프로젝트 저장 설계](PROJECT_WORKSPACE_DESIGN.md)를 따른다.
