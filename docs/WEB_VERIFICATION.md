초기 반복 실행에서 연속 결과 저장 중 React185가 발생해 일부 성공 결과가 통신 실패로 잘못 보였다. 네트워크 예외 처리와 상태 갱신을 분리하고 일괄 결과·진행 갱신에 `startTransition`을 적용했다. 입력 오류·후보 없음·HTTP 실패를 구분한 반복 검증을 통과했다. 접근성 검사는 Cloudscape 진입 애니메이션의 완료를 기다린 뒤 수행한다.

TTA 공식 상세에서 R3·2023-12-06 개정·유효 이력을 확인했고 AWS 공식 평가 지침의 Applications/Infrastructure/Networks/Migration 항목을 읽고 범용 입력에 연결했다. 상세 링크·적용 범위는 [견적 항목과 근거](ESTIMATION_INPUTS.md)에 있다. 공개 예제는 전부 합성이며 특정 고객의 원문·서버 정보·업무 링크를 포함하지 않는다.

## 수치와 API

마이그레이션 13개 테스트는 독립 산술, 실측/확정 경로, 분산 여부, 장애 생존 수, 고정 메모리 복제, 성장·상대성능, ARM/OS, gp3 한도·비율, 지속 EBS의 MiB/s→MB/s, 누락 가격, 잘못된 입력 및 불변성을 검증한다.

- 워크북 예제: CPU `9.6 vCPU`, 메모리 `47 GiB`, gp3 논리/설정 `450 GiB`.
- m8i.4xlarge Linux·730시간·1노드: 컴퓨트 `759.7256`, EBS `61.56`, 소계 `821.2856 USD`. EBS는 사용 시간과 별도로 한 달 보관한다.
- 3노드·1장애·균등 분산 확인: 노드당 `4.8 vCPU / 26 GiB`. 미확인 시 전체 부하를 노드마다 복제한다.
- Windows는 라이선스 포함 `RunInstances:0002` 단가를 선택한다. 다른 Windows 가격 행을 혼용하지 않는다.
- 기존 21개 규칙은 UI에서 재작성하지 않는다. 세 프로파일의 API 응답 전체를 기존 Python 코어와 대조한다.
- HTTP는 중복 키·NaN·UTF-8 오류·2MB 초과·임의 문서 경로·신뢰하지 않는 Host를 검사한다. 원본 없는 환경은 404와 명시적 안내를 반환한다.

1440px 데스크톱과 390px 화면·다크 모드를 렌더로 확인했다. 마이그레이션 산정서를 브라우저 인쇄 CSS로 A4 PDF 4페이지 생성하고 PDF 텍스트에서 입력·가정·9.6/47/450·비용·7개 섹션·출처가 모두 존재함을 확인했다. 첫 페이지와 계산/비용 페이지를 이미지로 렌더해 잘림·겹침을 검토했다. 다른 브라우저의 인쇄 엔진은 별도 검증 대상이다.

## 공개 재현과 한계

공개 stage만 새 디렉터리에 체크아웃하고 `reference/`·전체 추출이 없는 상태에서 `npm ci`, production build, Wiki gate·CLI를 통과했다. 별도 Python3.13 가상환경에 requirements를 새로 설치한 뒤 Python71개·브라우저8개(16.8초)를 다시 통과했다. 브라우저 서버도 이 공개 후보 디렉터리에서 기동했다.

원본·전체 추출본을 제외한 체크아웃에서는 문서/식·예제·카탈로그 검증과 계산·브라우저 기능이 실행돼야 한다. 로컬에 `reference/`가 있으면 원본 누락과 해시 변경을 검사하며, 원본이 전혀 없는 공개 체크아웃은 manifest에 등록된 로컬 파일 링크만 선택적으로 제외한다. 임의의 깨진 링크는 계속 실패한다. 이 차이는 회귀 테스트로 검증한다.

카탈로그는 한정된 36개 사양이다. 단일 gp3/노드, 서울 On-Demand·USD 범위이며 RDS·다중 볼륨·라이선스 전략·Savings Plans·실제 AZ/계정 가용성은 포함하지 않는다. 상대성능·균등 분산은 사용자 가정이다. 엑셀 네이티브 재계산, 원본 가이드/워크북 해시 불일치, HWP 표·그림 및 현행 보안 기준 대조는 미완료다.
