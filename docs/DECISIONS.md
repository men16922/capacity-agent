# Decisions

## 2026-09-27

- 원본 파일은 경로 그대로 보존하고 동일 SHA-256의 중복만 논리적으로 묶는다.
- LLM Wiki는 온프레미스 인프라 지식 기반이다. LLM 서빙/GPU 산정으로 범위를 확대하지 않는다.
- 엔진1.0.0은 TTA R3·강의 네트워크·2021 네트워크 가이드를 별도 프로파일로 구현한다. 기존 XLS와 AWS 엑셀은 이 규칙에 섞지 않는다.
- 수치 계산은 결정론적 도구가 소유한다. LLM은 입력 해석·추가 질문·근거 설명을 맡는다.
- tpmC와 SPC 결과는 시험 구성에 귀속한다. 벤치마크 종류·버전·상태가 다른 결과를 자동 혼합하지 않는다.
- 초기 단계는 Wiki/계산 엔진/하네스 초기화였다. 무인 루프용 `[auto]` 승격 및 자동 커밋 실행은 하지 않는다.
- runner와 engineering bible은 플러그인에서 사용하고 복제하지 않는다. 저장소 내 설정만 유지한다.

## 계산 엔진1.0.0의 계약

- 수치 입력은 십진 문자열로 고정한다. float 손실을 막고 원 입력을 trace에 보존한다.
- 중간 나눗셈은 정확한 유리수, 입출력은 Decimal을 사용한다. 반복소수의 정확한 분자/분모와 표시 문자열을 구분한다.
- 원문 MB는 별도 토큰으로 보존한다. 물리 단위로의 해석을 암묵적으로 선택하지 않는다.
- 네트워크 본문 표의 안정성 1~1.5를 우선한다. UI 설명의1~2와 충돌을 공개하고 업링크 인터페이스·이중화 정책은 사용자 입력으로 명시한다.
- AWS 사용 가이드와 현재 엑셀의 해시가 다르므로 동일 버전으로 간주하지 않는다. AWS 전용 계산은 별도 모듈로 유지하며, 이후 사용자 지시로 P2에 포함했다.

## On-Prem/AWS 웹 목표

- 사용자 지시: 상위 On-Prem/AWS 메뉴, Cloudscape, On-Prem 사양→AWS 마이그레이션이 핵심 기능. AWS 실측·EC2·gp3·비용을 P2로 승격한다.
- 계산은 기존 Python 코어와 별도 마이그레이션 모듈이 소유한다. React에서 식을 중복 구현하지 않는다.
- 초기 실행·검증은 로컬이며 공식 공개 사양·가격 스냅샷을 이용한다. 실제 AWS 자원 생성·데이터 이관은 수행하지 않는다.

## 공개·재현·저장

- 사용자 요청으로 웹 완료 후 public GitHub 저장소에 commit·push한다. 원본·전체 추출·사용자 입력·환경정보는 제외하고 출처 카드·규칙·코드·카탈로그를 공개한다.
- 공개 체크아웃은 원본 없이 실행한다. 로컬 원본이 있으면 기존 해시 검증을 계속 적용하고, 없는 원본 링크는 UI에서 구분한다.
- 브라우저당 한 프로젝트를 저장한다. 이전안 복제는 저장 당시 원본을 유지하고 JSON 가져오기는 입력부터 재계산한다.
- 후보 비용은 EC2·gp3 소계다. 시간당 Windows 라이선스 포함 operation과 EBS GiBps-mo 단위를 명시적으로 구분한다.

## 2026-09-28 — 다수 자산·공식 근거

- AWS 진입 화면은 최대200개 자산 목록이다. WEB/WAS·DB·BATCH는 역할 분류이며 서버들을 역할별 단일 자산으로 합치지 않는다.
- 일괄 산정은 검토 전 초안을 만든다. 사람의 확인 후 저장한 이전안과 분리하고 변경된 원본·조건의 과거 초안은 비용 합계에서 제외한다.
- 저장은 선택 후보만 유지하고 전체 후보는 상세에서 재조회한다. JSON 가져오기는 현재 엔진으로 재계산하며 외부 결과 금액을 신뢰하지 않는다.
- 표준·공식 문서명과 웹 링크를 먼저 표시하고 내부 ID·파일·해시는 추적용으로 유지한다. 표시 단위만 번역하고 원문 MB와 계산 JSON을 변경하지 않는다.
- 견적 조사 항목은 AWS 공식 평가 지침에 연결한 범용 필드로 구성한다. 비공개 고객 정보·기업별 분류를 기본 모델이나 공개 예제에 포함하지 않는다.
